# 🏢 On-Premise Enterprise AI (Закрытый ИИ Контур для ТОО)

> **Автономный корпоративный ИИ без передачи данных в зарубежные облака.**  
> Полная изоляция инженерных чертежей (DWG/DXF), ГОСТов, ТУ и внутренних регламентов внутри локальной инфраструктуры предприятия на серверах с видеокартами NVIDIA.

## 🚀 Возможности системы

1. **On-Premise Инференс (vLLM / Ollama на Ubuntu + NVIDIA):**
   - Движок **vLLM** с непрерывным батчингом (`Continuous Batching`) и оптимизацией памяти `PagedAttention`. Модели не зависают при одновременных запросах сотрудников.
   - Поддержка открытых моделей **Qwen 2.5 (14B / 32B-AWQ)** с идеальным пониманием русского и казахского языков, инженерных терминов и формул.

2. **Мультиагентный конвейер:**
   - **🛡️ Агент-Страж (DLP / Guardrail):** фильтрация конфиденциальных данных (пароли, платежные реквизиты, попытки несанкционированного дампа БД) и контроль прав пользователя (RBAC).
   - **⚙️ Агент-Инженер (RAG Worker):** контекстный поиск по базе ГОСТов, допусков и спецификаций металлоконструкций.
   - **👔 Агент-CEO / Аудитор:** перекрестная проверка ответа на отсутствие галлюцинаций и формирование официального отчета ТОО.

3. **RAG по технической документации и чертежам:**
   - Парсинг чертежей **DXF/DWG** (извлечение текстовых слоев, марок стали, позиций, анкерных болтов).
   - Индексация стандартов **ГОСТ / СПДС / СНиП**.

4. **Open WebUI для 15 сотрудников:**
   - Разделение прав доступа, история сессий, защита от внешней регистрации (`ENABLE_SIGNUP=false`).

## 🛠 Быстрый локальный запуск прототипа

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Запуск сервера:
```bash
python -m uvicorn app.main:app --host 127.0.0.1 --port 8080 --reload
```
Откройте браузер по адресу: **`http://localhost:8080`**.

---

## 🐳 Развертывание в продакшене (Docker Compose на сервере Ubuntu с GPU):

```bash
cd deploy
docker compose up -d
```
Все 4 сервиса (vLLM, Qdrant, Multi-Agent Core, Open WebUI) поднимутся в изолированной сети Docker без доступа наружу.
